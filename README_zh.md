## 全能型 SEO 平台

适合一站式开展关键词调研、竞品情报挖掘、外链审计与排名监控的综合平台。

- [Ahrefs](https://ahrefs.com/) - 业界权威的外链索引库，提供强大的关键词探索器（Keywords Explorer）与竞品内容差距（Content Gap）分析。
- [Semrush](https://www.semrush.com/) - 覆盖自然搜索、关键词魔法工具（Keyword Magic Tool）、竞品流量分析与 PPC 调研的综合营销套件。
- [SE Ranking](https://seranking.com/) - 高性价比全能 SEO 平台，支持深度排名追踪、竞品调研与整站健康度审计。
- [Moz Pro](https://moz.com/products/pro) - 经典 SEO 软件，创立了 Domain Authority (DA) 与 Page Authority (PA) 核心指标。
- [Ubersuggest](https://neilpatel.com/ubersuggest/) - 适合新手与中小站长的入门工具，提供关键词建议、竞品流量概览与站点基础审计。
- [Mangools](https://mangools.com/) - 界面简洁直观的轻量工具组合，包含 KWFinder、SERPChecker、SERPWatcher、LinkMiner 与 SiteProfiler。
- [Serpstat](https://serpstat.com/) - 适合成长型团队的 SEO 平台，支持域名批量分析、关键词聚类与竞品分析。
- [SpyFu](https://www.spyfu.com/) - 擅长历史数据回溯的竞品工具，可深入追踪对手的自然排名历史与 Google 广告投放词。
- [SEO PowerSuite](https://www.link-assistant.com/) - 经典桌面端 SEO 套件，包含 Rank Tracker、WebSite Auditor、SEO SpyGlass 及 LinkAssistant。
- [CognitiveSEO](https://cognitiveseo.com/) - 深度外链审计、惩罚恢复与页面内容优化分析工具。

## SERP 分析与关键词研究

用于查询实时搜索结果、发掘高价值长尾词、分析搜索意图（Search Intent）并评估竞争难度的核心工具。

- **[SERPScoreLite](https://serpscorelite.com/)** - 免费、免注册的轻量级 SEO 工具箱，基于实时 Google SERP 分析与 Ahrefs DR 权威信号提供关键词难度（KD）评分、URL 流量潜力预估及域名对比。
- [Google Keyword Planner](https://ads.google.com/home/tools/keyword-planner/) - Google 官方免费工具，提供最权威的搜索量历史基数、季节趋势及商业 CPC 参考。
- [AnswerThePublic](https://answerthepublic.com/) - 基于真实搜索联想，将用户的提问（Why/How/What）、介词搭配可视化展现的长尾词挖掘工具。
- [Keyword Tool](https://keywordtool.io/) - 利用 Google、YouTube、Bing、Amazon 等搜索引擎自动联想功能挖掘海量长尾词。
- [LowFruits](https://lowfruits.io/) - 蓝海长尾词挖掘神器，专用于发现大站未覆盖、论坛（Reddit/Quora）主导的高机会低难度词。
- [Ahrefs Keyword Generator](https://ahrefs.com/keyword-generator) - Ahrefs 免费工具，可针对目标词免费生成最多 150 个关键词建议及难度评分。
- [Semrush Keyword Magic Tool](https://www.semrush.com/analytics/keywordmagic/start) - 拥有超大规模关键词库，支持意图过滤与提问词筛选。
- [KeySearch](https://www.keysearch.co/) - 亲民的高性价比关键词难度查询、LSI 词挖掘与竞品关键词差距分析工具。
- [WordStream Free Keyword Tool](https://www.wordstream.com/keywords) - 快速关键词发掘工具，支持按行业筛选及搜索量对比。
- [kwrds.ai](https://www.kwrds.ai/) - 专注于长尾问题与搜索意图探索的关键词生成器。

## 技术 SEO 与站点爬虫

确保搜索引擎爬虫能顺利抓取、渲染、索引并正确理解网站架构与内容。

- [Google Search Console](https://search.google.com/search-console/about) - 站长必备官方工具，监控网页收录索引、核心网页指标（CWV）、抓取错误及搜索点击率。
- [Bing Webmaster Tools](https://www.bing.com/webmasters/about) - Bing 官方站长平台，提供诊断报告、关键词调研与 URL 即时提交（IndexNow）功能。
- [Screaming Frog SEO Spider](https://www.screamingfrog.co.uk/seo-spider/) - 业内事实标准的桌面爬虫软件，可深度扫描死链、重定向链、元标签缺失、重复内容及 JS 渲染问题。
- [Sitebulb](https://sitebulb.com/) - 广受好评的桌面端网站审计工具，提供可视化抓取路径图与按优先级排序的修复建议。
- [Lumar](https://www.lumar.io/) (原 DeepCrawl) - 企业级云端网站架构与健康监测平台，专为百万级大型网站设计。
- [LibreCrawl](https://librecrawl.com/) - 免费开源的现代化 SEO 爬虫，支持 Playwright 无头浏览器 JS 渲染及内存分析。
- [SEOnaut](https://seonaut.org) - 开源技术 SEO 审计工具，支持桌面运行及自托管部署。
- [Siteliner](https://www.siteliner.com/) - 快速诊断站内内容重复率、页面权重分布与死链的在线工具。
- [BROWSEO](https://www.browseo.net/) - 纯净呈现搜索引擎机器人眼中页面文本与结构的诊断工具。
- [PreRender24](https://prerender24.com/) - 基于边缘计算的预渲染服务，为单页面应用（React/Vue/Angular）向搜索引擎交付完整 HTML。

## 页面与内容优化

结合 SERP 首页竞争对手数据，优化内容相关性、主题权威度（Topical Authority）与结构标签。

- [Surfer SEO](https://surferseo.com/) - 基于 SERP 首页竞品对比，提供 NLP 关键词建议、内容大纲与段落层级优化的行业标杆。
- [Clearscope](https://www.clearscope.io/) - 企业级内容优化平台，专注搜索意图契合度、实体覆盖率（Entity Coverage）与可读性评分。
- [Frase](https://www.frase.io/) - 快速提炼 SERP 竞品要点，一键生成高质量内容大纲与优化建议。
- [MarketMuse](https://www.marketmuse.com/) - 深度语义审计与主题建模工具，帮助构建完整的话题集群（Topic Clusters）。
- [NeuronWriter](https://neuronwriter.com/) - 结合 Google NLP 建议的语义编辑器，支持竞品大纲提取与站内内链建议。
- [Rank Math](https://rankmath.com/) - 现代化 WordPress SEO 插件，内置 Schema 结构化数据、索引监控与 404 追踪。
- [Yoast SEO](https://yoast.com/) - 老牌 WordPress SEO 插件，提供 XML Sitemap 生成、规范标签（Canonical）及可读性检查。
- [ContentSwift](https://github.com/hilmanski/contentswift) - 面向创作者的开源内容研究与关键词优化工具。

## 外链分析与外链建设

监控网站外链健康度、评估反向链接质量、挖掘竞品外链策略并开展外链拓展（Outreach）。

- [Majestic](https://majestic.com/) - 历史悠久的外链索引库，拥有 Trust Flow (TF) 与 Citation Flow (CF) 权威指标。
- [Ahrefs Backlink Checker](https://ahrefs.com/backlink-checker) - 行业领先的外链核验工具，实时查看 Domain Rating (DR)、锚文本分布与引用域数量。
- [Monitor Backlinks](https://monitorbacklinks.com/) - 自动化监控自身与竞品外链变动，及时发现掉链及负面 SEO 风险。
- [Respona](https://respona.com/) - 专为外链建设者与公关团队打造的外联沟通与邮箱触达平台。
- [BacklinkScan](https://backlinkscan.com/) - 快速便捷的外链检查与锚文本检测工具。

## 排名追踪与可见度监控

精准监控关键词在不同地域、设备及 SERP 特性中的每日排名变化。

- [AccuRanker](https://www.accuranker.com/) - 业内速度最快的企业级排名追踪工具，支持秒级按需手动刷新与历史趋势对比。
- [SERPWatcher](https://mangools.com/serpwatcher/) - Mangools 旗下工具，界面清爽，通过“表现指数”直观反映排名整体健康状况。
- [Nightwatch](https://nightwatch.io/) - 支持全球细分到城市维度的本地地图包（Local Pack）、桌面与移动端精准排名追踪。
- [SerpBear](https://docs.serpbear.com/) - 开源自托管排名监控工具，原生支持 Google Search Console 接入与无限关键词追踪。
- [ProRankTracker](https://proranktracker.com/) - 专业级排名跟踪与多维度客户报表生成系统。

## 本地 SEO

提升 Google 地图、Google 商家档案（GBP）及本地搜索（Local 3-Pack）曝光率。

- [Google Business Profile](https://www.google.com/business/) - Google 商家档案管理核心入口，直接影响本地搜索排名与用户评价信号。
- [BrightLocal](https://www.brightlocal.com/) - 覆盖本地排名追踪、引文（Citations）建立与评价管理的本地 SEO 综合套件。
- [Whitespark](https://whitespark.ca/) - 知名本地引用源查找、本地包排名追踪与客户评价搜集工具。
- [LocalFalcon](https://www.localfalcon.com/) - 可视化网格排名追踪器，精准呈现以物理门店为中心各方位的地图排名强弱。
- [Moz Local](https://moz.com/products/local) - 本地商户信息多平台自动分发与同步工具，确保 NAP（名称、地址、电话）全网一致性。

## 网页性能与 Core Web Vitals

提升网站加载速率与交互流畅度，优化符合 Google 核心网页指标（LCP、INP、CLS）。

- [PageSpeed Insights](https://pagespeed.web.dev/) - Google 官方性能评测工具，综合 CrUX 真实用户体验数据与 Lab 实测环境给出优化指引。
- [GTmetrix](https://gtmetrix.com/) - 经典性能分析工具，提供详尽的加载瀑布流（Waterfall Chart）与瓶颈诊断。
- [Google Lighthouse](https://developer.chrome.com/docs/lighthouse/overview/) - 开源自动化评测工具，覆盖性能、可访问性、PWA 与 SEO 基准。
- [DebugBear](https://www.debugbear.com/test/website-speed) - 持续追踪 Core Web Vitals 变化并提供性能退化警报的监控工具。
- [Pingdom Speed Test](https://tools.pingdom.com/) - 简便直观的多节点全球网页加载速度测试工具。

## SEO 浏览器插件

在日常浏览网页时，快速查看页面元数据、层级结构与 SERP 指标。

- [Detailed SEO Extension](https://detailed.com/extension/) - 极度推荐的一键式 On-Page 检查扩展，瞬间解析 Title、Description、H 标签、Canonical、Robots 与 Schema。
- [SEO Minion](https://seominion.com/) - 包含页面诊断、死链检查、SERP 预览与 Hreflang 校验的多合一浏览器插件。
- [SEOquake](https://www.seoquake.com/) - Semrush 出品的经典插件，快速查看页面基础指标、内外部链接与 SEO 综合诊断。
- [Ahrefs SEO Toolbar](https://ahrefs.com/seo-toolbar) - 集成页面 SEO 报告、重定向追踪与 SERP 浮动指标的官方工具栏。
- [Redirect Path](https://chrome.google.com/webstore/detail/redirect-path/aomidfkchockcldhbkggjokdkkebmdll) - HTTP 状态码与重定向链（301/302/404）检测神器。
- [META SEO Inspector](https://chrome.google.com/webstore/detail/meta-seo-inspector/ibkclpciafdglkjkcibmohobjkcfkaef) - 快速排查页面 Meta 标签设置疏漏与合规性。
- [Similarweb 插件](https://chrome.google.com/webstore/detail/similarweb-traffic-rank-w/hoklmmgfnpapgjgcpechhaamimifchmp) - 随时查看目标站点的全球排名、月度访问量及流量渠道分布。

## 结构化数据与校验工具

生成并校验富媒体结果代码、检测 robots.txt 与网站地图配置。

- [Google Rich Results Test](https://search.google.com/test/rich-results) - Google 官方测试工具，检验页面结构化数据是否具备富媒体摘要展示资格。
- [Schema Markup Generator](https://technicalseo.com/tools/schema-markup-generator/) - Merkle 出品的免费工具，快速生成文章、FAQ、组织及本地商户 JSON-LD 代码。
- [XML Sitemap Validator](https://www.xml-sitemaps.com/validate-xml-sitemap.html) - 快速检测 XML 网站地图的格式错误与解析异常。
- [Robots.txt Validator](https://technicalseo.com/tools/robots-txt/) - 语法检查并验证 robots.txt 对各大主流搜索引擎爬虫的屏蔽规则。
- [ogimg.xyz](https://ogimg.xyz/) - Open Graph 社交分享图片自动化生成服务，提高社交点击率。
