# Contributing to Awesome SEO Tools

Thank you for your interest in contributing to **Awesome SEO Tools**!

## Inclusion Guidelines

To keep this repository authoritative, high-quality, and strictly focused on Search Engine Optimization (SEO), all suggestions must adhere to the following criteria:

1. **Directly Relevant to SEO**: The tool must solve a concrete SEO problem (e.g., keyword research, live SERP analysis, technical auditing, rank tracking, backlink analysis, on-page optimization, or performance).
2. **No Generic / Unrelated Submissions**:
   - ❌ Generic AI chatbots or LLM wrappers without specific SEO workflow value.
   - ❌ Unrelated infrastructure, general databases, call center software, hotel/restaurant booking SaaS, or ERPs.
   - ❌ Low-quality or duplicate spam directories.
3. **Active and Functional**: The service must be live, stable, and accessible.
4. **Objective Description**: Provide a 1–2 sentence factual summary of what the tool does without marketing hype or exaggerated claims.
5. **No Duplicates**: Search the repository before opening a pull request to verify that the tool isn't already included.

## How to Submit a Pull Request

1. Fork this repository.
2. Add your entry to the bottom of the most relevant category in `README.md` (and `README_zh.md` if applicable).
3. Use the following markdown format:
   ```markdown
   - [Tool Name](https://tool-url.com/) - Clear, concise 1-2 sentence description.
   ```
4. Commit your changes with a clear commit message (e.g., `Add ToolName to Technical SEO`).
5. Open a Pull Request for review.
